# 단청 생성기 (dancheong) — 설계

작성일: 2026-10-01 · 상태: 사용자 검토 대기 · 공개 저장소 `polos0117/dancheong` · 배포 `https://polos0117.github.io/dancheong/`

## 1. 목적

한국 전통 건축의 **단청**을 규칙으로 만들어 내는 웹 생성기. 누르면 새 문양이 나오고, 배경화면 크기로 저장하고, 링크로 공유한다.
보여 줄 작품(포트폴리오)이 목적 — 처음 보는 사람이 10초 안에 "단청이다, 예쁘다"고 느끼게.
전통 규칙을 따르되 **학술적 재현이 아니라 단순화한 것**이고, 화면에 그렇게 밝힌다.

### 성공 기준

- 어떤 씨앗이든 보면 단청으로 알아본다(머리초·휘·연꽃·빛넣기·먹선/분선이 있다).
- 같은 씨앗이면 언제 어디서 열어도 같은 문양. 주소(`?seed=`)로 공유된다.
- SVG·PNG 로 깨짐 없이 저장된다. 휴대폰·PC 배경 크기 그대로.
- 부분 이름표를 켜면 각 부분이 무엇인지 한 줄로 배운다.
- 휴대폰 화면(390px)에서도 쓸 수 있다. 런타임 의존성은 React 뿐.

### 범위 밖 (1차)

실제 건물 사진 위에 입히기, 3D, 사용자가 직접 칠하기, 별화(그림)·비단무늬 외 복잡한 금문, 다국어.

## 2. 단청의 구성 (이 생성기가 따르는 규칙)

### 색 — 전통 안료 이름의 고정 팔레트

| 이름 | 쓰임 |
|---|---|
| 뇌록 | 바탕(청록). 계풍·여백 |
| 석간주 | 적색 계열의 가장 어두운 색, 테두리·띠 |
| 장단 | 주황빛 붉은색 |
| 황 | 노랑 |
| 삼청 | 짙은 파랑 |
| 양록 | 밝은 초록 |
| 다자 | 자줏빛 갈색 |
| 먹 | 검은 선 |
| 백분 | 흰 선·가장 밝은 빛 |

색 계열(청·녹·적·황·자) 마다 **어두운 → 밝은** 단계 3개 + 백분. 정확한 색값은 구현 때 정하고(화면에서 조화·대비 확인), 팔레트 밖 색은 쓰지 않는다.

### 빛넣기

한 색 띠는 같은 계열을 **어두운 색부터 밝은 색으로** 2~4단 겹쳐 그린다(예: 삼청 → 밝은 청 → 하늘색 → 백분). 띠와 띠 사이에는 **먹선**(검은 선)과 **분선**(흰 선)을 긋는다.

### 보 한 칸 (가로로 긴 구성)

```
| 머리초 |        계풍        | 머리초 |
  ~30%           ~40%           ~30%      (좌우 머리초는 거울 대칭)
```

- **머리초**(보 끝부터 안쪽으로): 끝 테두리 → **휘** 2~4겹(꽃잎 모양이 세로로 늘어선 띠, 겹마다 빛넣기) → **주화**(연꽃, 꽃잎 8·10·12·16장, 꽃잎마다 빛넣기) → 가운데 **석류동**(있거나 없거나). 주화 위아래에 **반주화**(반쪽 꽃)가 있거나 없거나.
- **계풍**: 모로단청은 뇌록 바탕으로 비워 두고 가장자리에 먹선·분선만. 금단청은 **금문**(반복 기하 무늬: 고리금·삼각금·바자금 중 하나)을 빛넣기 색으로 채운다.

### 머리초 확대 (정사각형)

주화를 가운데 크게, 바깥으로 휘를 **원형으로** 2~4겹 두른 문양. 네 귀퉁이는 뇌록 바탕 + 작은 반주화 또는 금문 조각.

## 3. 생성기 화면

```
 단청 생성기                                  [이름표 ☐]
 ┌──────────────────────────────────────────────┐
 │                                              │
 │               (문양 SVG)                      │
 │                                              │
 └──────────────────────────────────────────────┘
 [새로 만들기]  씨앗 [ 4821 ]  양식 (모로 | 금단청)
 비율 (보 | 머리초 | 휴대폰 9:16 | PC 16:9)
 [SVG 저장] [PNG 저장] [링크 복사]
 단청의 구성을 단순화한 생성기예요 — 실제 단청과 다를 수 있어요.
```

- **씨앗**: 0~99999 정수. [새로 만들기]는 새 씨앗을 고른다. 씨앗·양식·비율은 주소(`?seed=4821&style=geum&ratio=phone`)에 들어가고, 주소로 열면 그대로 복원.
- **씨앗이 정하는 것**: 꽃잎 수, 휘 겹 수와 모양(둥근 꽃잎·뾰족 꽃잎), 머리초 띠들의 색 계열 배치(인접한 띠는 다른 계열), 석류동·반주화 유무, 금문 종류.
- **비율**: 보(3:1), 머리초(1:1), 휴대폰(9:16 — 머리초 확대를 세로로, 위아래는 계풍/금문 띠), PC(16:9 — 보 한 칸을 가운데에, 위아래 뇌록).
- **이름표**: 켜면 부분마다 이름 + 한 줄 설명이 그림 위에 나타난다(저장 이미지에는 넣지 않음).
  머리초 · 휘 · 주화 · 석류동 · 계풍 · 금문 · 빛넣기 · 먹선/분선.
- **저장**: SVG(그대로), PNG(비율별 고해상도: 보 3000×1000, 머리초 2048×2048, 휴대폰 1170×2532, PC 2560×1440). 파일 이름 `dancheong-4821-geum-phone.png`.
- **링크 복사**: 지금 주소를 클립보드로, "링크를 복사했어요" 알림.
- 라이트·다크는 시스템 설정. 그림 자체는 늘 전통 색. 휴대폰 폭에서 조작판은 세로로 쌓인다. 키보드로 모두 조작 가능, 그림에는 `role="img"` + "단청 문양, 씨앗 4821, 금단청" 같은 설명.

## 4. 구성

```
src/lib/rng.ts          씨앗 → 결정적 난수 (mulberry32)
src/lib/palette.ts      안료 이름·색값·계열별 빛 단계
src/lib/design.ts       씨앗 → 문양 설계값(꽃잎 수, 휘 겹, 색 배치, 금문 종류 …)
src/lib/meoricho.ts     머리초(가로 보 쪽·원형 확대) → 도형 목록
src/lib/geummun.ts      금문 타일 → 도형 목록
src/lib/compose.ts      비율·양식에 따라 전체 그림 = 도형 목록 + 이름표 위치
src/lib/svg.ts          도형 목록 → SVG 글
src/lib/url.ts          주소 ↔ { seed, style, ratio }
src/components/…        Canvas(그림), Controls(조작판), Labels(이름표)
```

- 도형 목록은 `{ kind: 'path'|'circle'|'rect', d/좌표, fill, stroke?, part }` 같은 순수 데이터. `part` 는 이름표·테스트용 부분 이름.
- React 19 + Vite + TypeScript. 런타임 의존성 React(+react-dom) 뿐. Vitest.
- PNG 는 SVG 를 이미지로 그려 캔버스에서 만든다(글자가 없어 웹 서체 문제 없음).
- GitHub Actions: `main` 에 push 하면 빌드 → Pages 배포(`base: '/dancheong/'`).
- Node 22(fnm).

## 5. 테스트

- 순수 모듈(Vitest):
  - 같은 씨앗 → 같은 설계값·같은 도형 목록, 다른 씨앗은 대체로 다름.
  - 보 구성의 좌우 머리초가 정확히 거울 대칭(도형 좌표가 가운데 기준으로 뒤집힌 값).
  - 빛넣기: 한 띠의 겹들이 늘 어두운 → 밝은 순서(명도 증가).
  - 주화 꽃잎이 정한 수만큼, 같은 각도 간격.
  - 모든 칠한 색이 팔레트 안.
  - 인접한 휘 띠는 다른 색 계열.
  - 주소 ↔ 상태 왕복, 잘못된 주소 값은 기본값으로.
  - SVG 글이 올바른 XML(파싱 가능), 도형 수가 합리적 범위.
- 화면: headless Chrome 으로 씨앗 여러 개 × 비율 4가지 스크린샷, 이름표 켜기, 390px 폭 가로 스크롤 없음, 저장 버튼이 파일을 만드는지. 배포 후 Pages 주소도 확인.
- 마지막으로 사용자가 눈으로 확인.
